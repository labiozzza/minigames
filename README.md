# MiniGames — PWA-платформа мини-игр. Игра №1: «Переливашки» (Water Sort)

Бесплатное приложение без рекламы, регистрации, трекеров и сервера.
После первой загрузки работает полностью офлайн. Стек: TypeScript (strict),
Vite, Phaser 4.2.1, Web Audio, Web Worker. Без UI-фреймворков.

## Требования

- Node.js >= 20.19 (проверено на Node 26.3.1), npm >= 10.

## Команды

```sh
npm ci                 # установка
npm run dev            # разработка (http://localhost:5173)
npm run build          # production-сборка в dist/
npm run preview        # проверка сборки (http://127.0.0.1:4173)
npm run typecheck      # проверка типов
npm run lint           # то же, что typecheck (без tw-сканера)
npm run test           # unit/integration (Vitest)
npm run test:levels    # массовая сертификация 10 000+ уровней
npm run test:e2e       # Playwright E2E на production-сборке
npm run icons          # перегенерация PWA-иконок (без зависимостей)
```

## Игра

Классические переливашки: собрать каждый цвет в отдельной пробирке,
два нажатия (выбрать → перелить), отмена/перезапуск/подсказка без лимитов.
Со 101 уровня — скрытые слои «?»: цвет открывается сверху и запоминается
навсегда (отмена и перезапуск знание не стирают).

Подсказка честна: доказанный ход — только по полностью известной позиции;
иначе помеченная «Разведка» либо честное отсутствие.

## Офлайн и обновления

Первая загрузка кеширует всё (Service Worker, `generateSW`). Дальше —
без сети: игра, уровни, подсказки, сейвы, экспорт/импорт. Обновление —
баннером по запросу, с сохранением прогресса.
