# MiniGames — PWA-платформа мини-игр

Бесплатное приложение без рекламы и трекеров. Ядро (**«Переливашки» /
Water Sort** и **«Водопроводчик» / Plumber**) работает **офлайн-first**: после
первой загрузки игра, уровни, подсказки и прогресс доступны без сети, без
регистрации и без сервера. Стек: TypeScript (strict), Vite, Phaser 4.2.1,
Web Audio, Web Worker, без UI-фреймворков.

Регистрация, облачная синхронизация, ежедневные/еженедельные испытания, обмен
уровнями, push и админ-панель — это **необязательный серверный слой** (`server/`).
Он реализован и протестирован, но **в production не развёрнут**: клиент к нему не
сшит, Postgres/домен/HTTPS требуют отдельного разрешения (см. `docs/DEPLOY.md`).
Отсюда два режима:

- **Локальный офлайн-режим** — всё, что нужно для игры, без сервера.
- **Серверные возможности** — только при явном подключении backend.

## Требования

- Node.js **20.19.0** (см. `.nvmrc`; проверено на 26.3.1), npm ≥ 10.
- Python **3.12** и Pillow — только для AssetGen-конвейера (`.python-version`).
- Playwright Chromium — для E2E (`npx playwright install chromium`).

## Команды

```sh
npm ci                 # установка (точные версии)
npm run dev            # разработка (http://localhost:5173)
npm run build          # production-сборка в dist/ (typecheck + vite build)
npm run build:test     # сборка с test-hooks (для E2E)
npm run preview        # проверка сборки (http://127.0.0.1:4173)
npm run check:release  # гарантия: в release dist нет test-hooks/секретов
npm run typecheck      # проверка типов
npm run test           # unit/integration (Vitest)
npm run test:levels    # массовая сертификация 10 000+ уровней
npm run test:server    # серверные тесты (с PG_URL — против реального Postgres)
npm run test:e2e       # Playwright E2E на сборке с hooks (desktop + mobile)
python3 -m unittest discover -s .opencode/skills/minigames-assetgen/tests  # AssetGen
```

CI-пайплайн (typecheck/unit/levels/build/server+Postgres/E2E/assetgen) лежит в
`docs/ci/github-workflows-ci.yml` — включение и локальные аналоги в
`docs/ci/README.md`.

## Игры

### «Переливашки» (Water Sort)
Классические переливашки: собрать каждый цвет в отдельной пробирке, два
нажатия (выбрать → перелить), отмена/перезапуск/подсказка без лимитов.
Со 101 уровня — скрытые слои «?»: цвет открывается сверху и запоминается
навсегда (отмена и перезапуск знание не стирают). Подсказка честна: доказанный
ход — только по полностью известной позиции, иначе «Разведка».

### «Водопроводчик» (Plumber)
Дискретная детерминированная симуляция: соедини источник и получатель
трубами, запусти воду. Цвета/конфликты, миксер, фильтр, распределитель,
клапаны, программы источников, коллекции и диорамы, испытания, шеринг.
Уровни генерируются и сертифицируются witness-реплеем (не подбор).

## Офлайн и обновления

Первая загрузка кеширует всё (Service Worker, `generateSW`), у каждой игры свой
runtime-кеш `mg-game-<id>-v<assetsVersion>`. Дальше — без сети. Обновление —
баннером по запросу, с сохранением прогресса; сейвы мигрируют по `schemaVersion`
(v1→v2→v3), перед миграцией пишется резервная копия.

## Статус готовности

Локально функциональное ядро, графика базы, сохранения, офлайн и регрессия
зелёные; серверный протокол реализован и протестирован. Не закрыто:
production-интеграция клиент↔сервер, env-арт, часть UX-механик, реальные
устройства. Итог — **READY_FOR_LOCAL_ACCEPTANCE**; `READY_FOR_PRODUCTION`
только после разрешённого stage/prod-развёртывания. Актуальные цифры и
пробелы — в `docs/final-acceptance-report.md`.
