# ARCHITECTURE — MiniGames

## Слои

```
shell (src/app) ── каталог, настройки, импорт/экспорт, install/update, роутер
  └── GameModule (src/platform/games/registry) ── mount/pause/resume/unmount
        └── water-sort (src/games/water-sort)
              ├── domain/        чистые правила, без Phaser/DOM
              ├── generation/    seeded PRNG + обратная конструкция + сертификат
              ├── solver/        IDA* (подсказки) + честный Hint Engine
              ├── workers/       генерация вне главного потока
              ├── presentation/  Phaser 4 сцена (только отрисовка)
              ├── tutorial/      (в game.ts) два интерактивных обучения
              ├── config/        неизменяемый баланс, палитра
              └── dev/           DEV-панель (tree-shaken из production)
platform/ ── storage (IndexedDB→localStorage), settings, i18n, pwa, ui
audio/ ── Web Audio синтезатор (музыка + эффекты), без файлов
```

## Жизненный цикл игры

1. `shell.playGame` размонтирует текущую игру (`unmount`: persist → stop audio →
   `game.destroy(true)` → remove DOM). Одновременно живёт **не более одного**
   `Phaser.Game`.
2. `mount` строит DOM-хром (HTML/CSS), восстанавливает сейв или генерирует
   уровень в Worker, создаёт `Phaser.Game` (явный `Phaser.WEBGL`; при отсутствии
   WebGL — понятный экран с возвратом в каталог, без чёрного экрана).
3. Логика применяется **атомарно и мгновенно** (`attemptPour`), анимация сцены
   лишь отображает переход «до → после». Во время анимации ввод заблокирован.
4. `visibilitychange` → пауза + persist + suspend Audio; возврат → resume.
   Игра не уничтожается при сворачивании.
5. Выход в каталог сохраняет активное состояние; повторный вход
   восстанавливает его точь-в-точь (пробирки, знания, историю).

## Состояние

- `SessionState`: пробирки (слои `{id,color}`), `known: Set<layerId>`,
  `history: PourMove[]`, начальная раскладка + начальные знания.
- Отмена двигает жидкость назад, но **не скрывает** раскрытое.
  Перезапуск возвращает раскладку, чистит историю, хранит знания.
  Повтор пройденного уровня начинает новую сессию с чистыми знаниями.
- Хранилище: IndexedDB (`minigames/kv`), fallback localStorage, `schemaVersion`,
  компактная история (ходы, не слепки). Квота → ошибка `storage-quota`,
  предложение экспорта, без молчаливой обрезки.

## Звук

Один `AudioEngine` на игру (создаётся в `mount`, `dispose` в `unmount`):
независимые громкости музыки/эффектов, эмбиент-аккорды по таймеру
(защита от двойного запуска), suspend при скрытии вкладки.
`AudioContext` создаётся только после жеста пользователя.

## Кеш и обновления

`vite-plugin-pwa`, `generateSW`, `registerType: 'prompt'`. Прекеш всего `dist`
при первой загрузке. Обновление: баннер «Доступна новая версия» → по кнопке
игра выгружается с сохранением, SW обновляется, интерфейс перезагружается.
Никакой принудительной перезагрузки посреди уровня.

## Границы честности подсказок

`HintEngine` получает только публичную проекцию (`toPublic`): известные цвета
и `unknown`. Полный `PuzzleState`, seed и генератор в модуль не передаются.
Доказанная подсказка (`hint`) — только для полностью известных позиций по пути
solver; иначе — помеченная `scout` разведка либо честное отсутствие.
