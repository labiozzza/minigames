# Stage 4 Report — Прогресс, коллекции и спецрежимы

## 1. Реализовано (клиент, без сервера)
- Режимы: child (1–2), normal (3–12), expert (13+) с независимой статистикой attempts/wins/hints/skips и curriculum семейств (`familyForLevel`).
- Звёзды 1–3 по эффективности + подсказкам; персистентны (`stars[mode:level]`), показаны в выборе уровней и баннере победы.
- Альбом: 12 коллекционных предметов (`COLLECTIBLES`), правила разблокировки (семейства/победы/звёзды/режимы), силуэты закрытых, диорама-заглушка при полном сборе (CSS). Арт переиспользует 11 тайлов атласа.
- Daily/weekly: сервер-независимая детерминированная генерация по UTC-дате (`daily-YYYY-MM-DD`, weekly Monday) — одинаковая задача у всех; архив; награды идемпотентны (`dailies[date]` max-merge). Серверный манифест (`/games/:id/challenges`) возвращает те же ID (контракт готов к серверной выдаче).
- Share: deep link `#/plumber-share/<base64url(def)>` (валидация размера/видов/сетки в `share-boot.ts`) + короткий код `P-M-12` (генерированные уровни) с экраном ввода. Прохождения шаренных — вне прогрессии.
- Уведомления: внутриигровые индикаторы (кнопка Daily с ★ за сегодня); push отсутствует и отключён по умолчанию согласно ТЗ.
- Локализация ru/en для всего нового UI; цели с цветовыми точками (без чтения); undo+redo; reduced-motion.

- E2E: выбор уровней, альбом (12 карточек), daily-кнопка присутствует, share UI — в plumber.spec PASS (desktop+mobile).
