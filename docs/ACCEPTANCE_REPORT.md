## Честные partial / not done

- **Физические устройства**: только эмуляция Playwright. iPhone/бюджетный Android не тестировались.
- **PWA install prompt**: headless не выдаёт `beforeinstallprompt`; автоматика E2E невозможна. Ручные шаги: открыть production-сборку в Chrome Android/Desktop → сыграть уровень → принять баннер; либо меню браузера → «Установить».
- **Update-пара версий**: E2E пары v1→v2 не гонялась (нужны две сборки); способ — `docs/DEPLOY.md`. Логика prompt/update покрыта кодом и ручным ревью.
- **Оптимальность решений**: не заявляется и не тестируется; сертификат = найденный легальный путь (длина 9–28 в выборке).
- **60 FPS / бюджетные устройства**: замеры FPS не проводились; есть адаптив декора и `prefers-reduced-motion`. Утверждений о 60 FPS нет.
- **Громкость/качество звука на слух**: синтез проверен отсутствием ошибок и вызовов; экспертная оценка звучания не проводилась.
- **merge/import через UI**: replace/merge/cancel покрыты unit-тестами и кодом; E2E кликает только export (скачивание) — импорт по файлу в headless-окружении ограничен.

## Найденные и исправленные ошибки

1. Тест поймал инвариант: ходы «только в пустые» никогда не перемешивают
   (все пробирки вечно полны/пусты) → замена на обратную конструкцию
   с расщеплением и доказуемым сертификатом.
2. IDA*: меж-итерационная transpose-таблица некорректна (bound растёт) → откат;
   эвристика усилена сегментами.
3. Клик по модальному диалогу над зоной пробирки выбирал её (Phaser слушает
   глобально) → блокировка игрового ввода при открытой модалке.
4. Переход «Далее» после победы требовал подтверждения (история не пуста) →
   выигранный уровень подтверждение не требует.
5. Строки DEV-панели попали в production-словари → удалены; код панели и так
   исключён (проверено grep).
6. Классические уровни показывали покрытые слои как `?` → `defaultKnownIds`:
   без скрытых видны все слои.
7. E2E-хрупкости тестов (нелегальные ходы, рестарт сессии, фокус) — исправлены
   сами тесты, продукт не менялся ради тестов.

## Доработка 15.10.2026: анимация, жидкость, онбординг

**Анимация переливания** (без физики, фейк для мобильных): подъём → перелёт
к точке над горлышком цели → наклон ±24° → фаза литья (уровни
интерполируются, струя течёт) → возврат → «успокоение» жидкости (220мс).
Струя — сужающийся полигон цвета слоя с бликом-ядром, колебанием и брызгой;
ширина пульсирует 5→10px.

**Композиция**: статичные пробирки depth 0, струя depth 20, анимируемая
пробирка — отдельный оверлей-контейнер depth 30 (оригинал скрыт), точка
нависания с запасом (0.85 ширины вбок, 0.88 высоты вверх) — стёкла не
пересекаются. Доказательства: `pour-stream-1/2.png`.

**Жидкость**: скруглённые слои, затемнение низа, светлая кромка сверху,
блик-полоса, мягкий мениск с колебанием; стекло — чистый контур 2.5px,
верхняя дуга-блик, боковой отблеск.

**Онбординг действием**: спотлайт (затемнение с отверстием, пульс-кольцо,
рука 👆/👇, карточка 3–6 слов + эмодзи). База: выбор → литьё в цвет →
выбор → литьё в пустую → Отмена → Подсказка → про «Заново» → 🎉.
Mystery: реальный scout-ход с живой разведкой → акцент раскрытия → Отмена
с демонстрацией сохранённого знания. Ошибочные тапы блокируются мягко
(покачивание + пульс, состояние не меняется). Повтор из настроек
(«🎓 Повторить обучение»). Доказательства: `tutorial-basic.png`,
E2E `tutorial.spec.ts` (прохождение только действиями + E2E mystery).

**Производительность**: нет per-frame работы (перерисовки только во время
анимаций), оверлей-объекты переиспользуются, instant-режим пропускает эффекты.
E2E-тайминги не выросли (flow desktop ~16–18с как раньше).

**Тесты доработки**: unit 26/26 (5 новых для `tutorial/logic`), E2E 14/14
(desktop+mobile, включая 2 новых tutorial-спека). Найденные баги:
Phaser-слушатель выбирал пробирку сквозь модалку (закрыто гейтом);
кольцо туториала перехватывало клики (pointer-events); карточка перекрывала
кнопки Undo/Hint на мобильном (карточка докируется наверх); старт туториала
раньше `scene.create` (старт по onReady + репоинт на resize).

**Компромиссы**: без честной физики (фейк); multi-unit ходы анимируются
упрощённо (растёт только верхний слой); тексты короткие с эмодзи (RU/EN).

## Исправление: исчезновение пробирки при переливании

**Первопричина**: архитектура «спрятать оригинал (`setVisible(false)`) →
показать копию в оверлей-контейнере → вернуть видимость в `onComplete`».
Любой обрыв tween-цепочки (исключение в кадре, resize/реlayout посреди
анимации с пересозданием объектов — на iPhone ресайзы регулярно происходят
при схлопывании тулбара Safari) оставлял оригинал скрытым навсегда, а струя
в отдельном слое продолжала рисоваться — «струя из воздуха».

**Исправление архитектурой, а не маскировкой**: оригинал больше никогда не
скрывается. Анимируется его собственный контейнер (позиция/наклон) с
поднятием depth 0→30 на время полёта; струя — отдельный слой depth 40.
Дети пробирки переведены в локальные координаты контейнера (вращение вокруг
центра пробирки, а не начала канваса). Добавлены: токен поколения анимации
(устаревшие tween-кадры после пересборки сцены выполняют snap к текущему
логическому состоянию и всё равно вызывают `done` — софт-лока нет),
кламп точки нависания в границы поля, аудит кадра (`srcVisible/srcInBounds/
streamOn`), стадии `lift/move/tilt/pour/return/settle`, доступные тестам.

**Проверка**: `tests/e2e/pour-stages.spec.ts` — порядок стадий через rAF-сэмплер
внутри страницы, аудит видимости/границ/струи, соседние пробирки, межрядовое
переливание (мобильная матрица, fast), multi-слой, instant-режим (без стадий,
логика + undo корректны). Видео полного переливания:
`evidence/video/pour-desktop.webm`, `pour-mobile.webm`; кадры стадий —
`evidence/stages/`. Итог: **E2E 20/20**, unit 26/26.
