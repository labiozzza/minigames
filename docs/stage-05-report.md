# Stage 5 Report — Общая серверная инфраструктура (local tier)

## 1. Реализовано: `server/` (node:http, ноль runtime-зависимостей)
- Auth: email OTP (6 цифр, 10 мин, 5 попыток, rate limit 5/час, без перечисления адресов), сессии 30 дней, привязка гостя без потерь.
- Saves/sync: версионированные сохранения, идемпотентные события по UUID (повторы игнорируются), конфликты active — «первый побеждает», достижения выводятся из сохранения.
- Challenges: детерминированные UTC-манифесты daily/weekly + resolve (seed совпадает с клиентской формулой).
- Share: создание/чтение кодов (лимит 16 КБ, rate-limit через размер), Config: публичный версионный срез.
- Admin: черновик → предпросмотр → публикация (версии) → откат + журнал аудита; доступ по роли, пользовательский API отделён.
- Telemetry: только с согласием, PII-поля вырезаются, лимит 100 событий/запрос.
- Хранилище: интерфейс Store + MemoryStore (тесты) + FileStore (атомарный JSON, локальный preview). Postgres — только интерфейс-адаптер в будущем (не развёрнут: нет одобрения на VPS-действия, нет доступного Postgres).

## 2. Проверки
- `npm run test:server` — **7/7 PASS**: auth/брутфорс/rate-limit, идемпотентность sync, конфликт active, детерминизм challenges, share roundtrip + oversize, admin publish/rollback/audit + 403, telemetry consent+PII.
- Клиент НЕ подключён к серверу (офлайн-first локальные сохранения — источник истины; контракт sync совместим с форматом событий клиента).
