# GENERATION — уровни Water Sort

## Версии и seed

- `GENERATOR_VERSION = ws-gen/1`, `BALANCE_VERSION = ws-bal/1`, `GAME_ID = water-sort`.
- Seed: `xmur3("water-sort|{level}|ws-gen/1|ws-bal/1")` → `mulberry32`.
  Никаких `Math.random()`, wall-clock, локали и CPU-зависимостей.
- Один номер уровня = одна головоломка у всех и всегда.

## Метод: обратная конструкция с расщеплением

1. Старт из решённого состояния (по 4 единицы каждого цвета + 2 пустые).
2. Серия обратных шагов: снять `k` верхних единиц цвета `c` с пробирки `T`
   на пробирку `U`, где либо `k` — строгая часть верхней группы
   (наверху `T` остаётся `c`), либо забирается вся пробирка целиком,
   а `U` пуста или показывает другой цвет (блок ложится ровно верхней группой).
3. Сертификат — обращение шагов в LIFO-порядке: перелить блок обратно.
   Каждый обратный ход доказуемо легален по правилам игрока и переносит ровно
   те же единицы (верхняя группа `U` — ровно блок; наверху `T` — `c` или пусто;
   место есть, т.к. `T` эти единицы уже держала).
4. Сертификат перепроверяется независимой симуляцией `applyPourToTubes` до победы.
   Невалидный кандидат не публикуется (конструктивно невозможен; проверка — пояс).

Почему не «тасование легальными ходами»: из решённого состояния легальный ход
может вести только в пустую пробирку целой группой — инвариант
«все пробирки полны/пусты» сохраняется вечно, смесь недостижима. Это проверено
тестом и зафиксировано здесь как осознанное следствие правил.

## Баланс (`config/balance.ts`, неизменяемый)

- Цвета: 1–100: 3→12; 101+: 10–12 волной. Пробирок: цвета + 2 (5–14).
- Шаги смешивания: `12 + цвета*3 + волна(0..8)`; решения обычно 9–28 ходов.
- Скрытые слои: 0 до 100; 101–300 рост доли до 50% (cap, не ровно);
  300+: волна. Верх каждой непустой пробирки всегда видим.
- Пустые пробирки: всегда 2.

## Solver и подсказки

- IDA* с бюджетом в **узлах** (не во времени), фиксированным порядком ходов,
  двумя безопасными отсечениями. Используется только для подсказок
  по полностью известным позициям и в DEV-панели. Оптимальность не заявляется:
  сертификат — это найденный легальный путь, метрика длины — длина пути.
- Глубокий полный перебор отдельно не запускался: обоснование — конструктивный
  сертификат для каждого из 10 000+ проверенных уровней (см. `evidence/`).

## Неизменность выпущенных уровней

Функция `levelNumber → puzzle` при версиях `ws-gen/1` + `ws-bal/1` frozen.
Любое изменение баланса, меняющее раскладки, — только через новый namespace
(новые версии + отдельная нумерация). Архивные конфигурации хранятся в этом файле
и в `balance.ts`. Регрессионные фикстуры (checksum уровней 1, 2, 100, 101, 300)
вшиты в `tests/levels/mass.test.ts`.
